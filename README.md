# Voca — Voice Vocabulary Coach

Voca is a lightweight, interactive vocabulary-learning prototype designed to help users build their English vocabulary through short daily practice sessions.

## 🚀 Live Demo

**[Try Voca — Voice Vocabulary Coach](https://ajeetku07.github.io/voca-voice-vocabulary-coach/)**

## ✨ Features

- **Daily Vocabulary:** Discover useful English words with definitions and example sentences.
- **Pronunciation Support:** Listen to words and their pronunciations using browser speech synthesis.
- **Interactive Quizzes:** Test your understanding with multiple-choice questions.
- **Sentence Practice:** Practice using vocabulary in your own sentences.
- **Personal Word List:** Save words for revision and review your progress.
- **Lightweight Interface:** A simple, browser-based experience with no installation required.

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Web Speech API for supported speech features
- GitHub Pages for deployment

## 🎯 Objective

The goal of Voca is to make vocabulary practice simple, engaging, and accessible through short, interactive learning sessions.

## ▶️ Run Locally

1. Clone this repository.
2. Open `index.html` in a modern browser.
3. Use Chrome for the best compatibility with supported voice features.
